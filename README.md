# Welcome to GamePlaza!

A website created by a Staten Island middle schooler who wanted an easy way to find games that are unblocked, without any VPNs or proxies. If a game gets blocked, you want to add a game, or edit something on the site, please go to the [Request page](https://docs.google.com/forms/d/e/1FAIpQLSdltdDYawD5naUl7gZbAJuKv4u13vMXt-XDTlmUP4LdpS7yAQ/viewform).

Since I am fairly new to coding, I am using some inspiration from another unblocked games website like GamePlaza, [Barnical](https://barnical.github.io/), and [frogies arcade](https://frogiesarcade.net/).
